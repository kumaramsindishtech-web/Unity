# Demo Scene Sample

This sample provides a pre-configured reactor scene for testing and learning.

## Contents

- Demo scene with reactor hierarchy
- Pre-configured materials
- Sample particle systems
- Ready-to-use simulation data

## Installation

1. In Package Manager, find "Industrial Reactor Simulator"
2. Expand "Samples"
3. Click "Import" next to "Demo Scene"

## Usage

1. Open the imported Demo Scene
2. Enter Play Mode
3. Open Tools > Industrial Reactor Simulator
4. Start simulation and experiment with controls

## Note

This sample requires the main package to be installed first.
